## Контекст

У 2021 році я працював Full Stack Developer у Career PRO і був єдиним розробником мобільного застосунку компанії. Ніхто в компанії раніше не працював з React Native, тож дослідження й вибір технології були на мені.

**Стек:** React Native, Apollo GraphQL, автоматизовані тести, CI/CD для мобільних релізів.

## Рішення

### 1. React Native, Swift чи Flutter

Swift покривав лише iOS. Flutter означав вивчати нову мову з нуля. React Native давав одну кодову базу для обох платформ і дозволяв перевикористати код, який у компанії вже був, тому я обрав його.

### 2. Спільне все, що не є UI

Бізнес-логіка, запити до API й типи жили у спільних пакетах, тож застосунку не доводилося заново реалізовувати правила, які вже існували.

### 3. Релізи без релізної команди

Я налаштував автоматизовані тести й CI/CD для мобільних збірок і сам займався публікацією в App Store та Google Play.

**Результат:** застосунок дійшов до реальних користувачів в обох магазинах, і я був на ньому єдиним розробником.
